# 行尾补量模型

本工具从指定访问模式求出一个元素数 (p)。行主序 FP32 数组的逻辑形状保持不变，访问时使用物理行距 (N+p)。给定基址 (B)，坐标 ((r,c)) 的线号为

```text
line = floor((B/4 + r*(N+p) + c) / 32)
set  = line mod S
```

模型使用 MRPB Base-S 的理想 L1 参数，即 16 KiB、4 路、128 B 行、32 组。涉及 L2 的局部推导采用 128 KiB、16 路、128 B 行的单分区、64 组取模模型。MRPB 的完整 L2 使用六个分区，分区及组映射没有足够细节供工具重建。[MRPB §2 和表 1](https://mrmgroup.cs.princeton.edu/papers/mrpb.pdf)

## 自定义相邻列复用

目标访问是一个 32-lane warp 按行展开，相邻两次迭代沿列前进一个元素。对落在同一条缓存线的两次访问，计算期间经过的不同同组线。理想 4 路 LRU 中，计数小于 4 时该线仍可复用。[CME 附录](https://mrmgroup.cs.princeton.edu/papers/toplas-ghosh.pdf)

逻辑行宽是 2,048 个 FP32 元素的整数倍时，基线行距的整行步长在两种模型中均整周期回绕。对于 (0<ple32)，矩阵干扰行数的上界为 (lfloor32/pfloor)。输入 (R) 为其他来源可能插入的不同同组线数。令上界加 (R) 小于 4，再向上取满足行首 32 B 对齐的补量。

```text
minimum = floor(32 / (4 - R)) + 1
p       = 8 * ceil(minimum / 8)
```

例如 (R=1) 时，最小整数下界为 11，按 8 个元素对齐得到 (p=16)。对于 (p=32)，不同 lane 的同列访问落在不同组，行内相邻复用的实际矩阵干扰上界为 0。因此当 (R=3)、通用上界不够紧时，直接选 (p=32)。(Rge4) 会耗尽四路模型的预算。自定义规则要求基址对齐能保证 32 B 行首对齐且至少有一个完整 warp 的行数，允许末尾部分 warp。

## 研究预设

| 算子 | 对应补量及机制 |
|---|---|
| ATAX、BiCG、MVT | (p=16)，相邻列复用窗口留一路给向量广播。 |
| SYRK | (p=8)，宽 256 的单矩阵跨行操作数只在一个极端 lane 距离出现同组干扰，再计入一条广播线。 |
| SYR2K | (p=32)，整行距取奇数条缓存线，给第二矩阵和两条广播留出预算。 |
| SRAD | (p=16)，系数阶段图像邻域与统计量所用的组内驻留约束。 |
| Gaussian | (p=8)，Fan1 跨行读取的组峰值和一次主元广播。该指标用于评估潜在请求压力。 |
| GEMM、2MM、3DCONV、FDTD、HotSpot、LUD、Backprop、K-means、Pathfinder | (p=0)，在已建模的访存阶段中保留紧凑布局。 |
| BFS | CSR 紧凑基线，现有表示没有可统一调整的矩形行距。 |

真实 GPU 的 warp 交错、实际缓存组映射、sector 有效性、写入和回填时序会影响观测结果。不同同组线的数量、窗口能否驻留、硬件缺失计数和执行时间分别记录。
